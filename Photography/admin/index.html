    安全检查建议

    • 对外提供服务时，请放在 HTTPS 反向代理之后，并确认 Cookie 带上了 Secure。
    • 登录失败会按 IP + 用户名限流锁定，锁定期间即使密码正确也会被拒绝。
    • 修改密码后，其它设备上的登录状态会立即失效。
    • 忘记密码时，在服务器上执行 python admin.py --reset-password。
